# Organização de assets

Os caminhos existentes foram preservados para não quebrar as referências atuais.

- `images/`: imagens de interface e produtos já utilizados pelas páginas.
- `images/produtos/`: imagens locais do catálogo e o fallback `placeholder.webp`.
- `icons/`: ícones SVG reutilizáveis.
- `background/`: imagens de fundo.

Novos assets devem manter nomes descritivos, minúsculos e separados por hífen. Não mover ou renomear arquivos já referenciados sem atualizar e testar todas as páginas consumidoras.
